# Coeur d'Alene Guys Weekend

Static trip-planning page. No build step.

- `index.html` is the whole page (markup, styles, script and map data).
- `maps/` holds the two shaded-relief backdrops for the regional map.
- Picks, crew and the payment ledger save in the visitor's own browser (localStorage). Nothing is sent to a server.

Deployed on Vercel as its own project with this folder as the root directory.
The maps are simplified and are not for navigation.
